# Plantilla de registro de cambios y pull

Copiar esta plantilla a la bitácora o a un documento enlazado. Completar únicamente con datos comprobados.

```text
Fecha y responsable:
Objetivo o problema:
Estado inicial y evidencia:
Qué se hizo:
Cómo y por qué:
Archivos creados, modificados o eliminados:
Funciones relevantes: propósito, entradas, salida y efectos:
Pruebas y resultados reales:
Riesgos, limitaciones y pendientes:
Incidencia Jira relacionada, si existe:

Solo para pull:
Rama local y remoto:
Commit anterior y commit final:
Cambios locales previos y revisión de conflictos:
Archivos o áreas que llegaron y qué cambió:
Conflictos y resolución:
Comandos y pruebas posteriores:
```

Antes de un pull, revisar `git status` y las referencias remotas disponibles. No ejecutar operaciones que descarten cambios locales. Una lista de commits o un diff pueden explicar cambios; no incluir información privada en la documentación.
