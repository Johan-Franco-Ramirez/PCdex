# Referencia del backend anterior

Estos archivos proceden de la rama `main` y corresponden a un backend distinto, con los modelos `User` y `Component`. Se conservan como referencia para una integración posterior; no forman parte del backend activo ni de sus migraciones.

El backend activo utiliza `Usuario` y `Componente`, las migraciones en `backend/prisma/migrations`, y la configuración Docker en `backend/compose.yaml`. No ejecutes la migración ni los scripts de esta carpeta contra la base de datos actual.
